# متغیرها؛ جعبه‌های داده
آموزش پایتون از صفر — درس ۲

داده‌ها را ذخیره کن، عوض کن، استفاده کن

فایل «variables.py»:
```python
name = "علی"
age = 15
print(name, age)
# ──── مثال ۲ — تغییر مقدار متغیر ────
score = 18
score = score + 2
print(score)   # 20
# ──── مثال ۳ — جابه‌جایی دو متغیر ────
a, b = 1, 2
a, b = b, a
print(a, b)   # 2 1
```

نکته: قانون نام‌گذاری: با حرف شروع شود، بدون فاصله؛ name و Name یکی نیستند
