# قالب افزودن انجمن یا کانال جدید — از این پوشه کپی کن

این قالب تضمین می‌کند هر انجمن/کانال جدید **کاملاً ایزوله** اضافه شود و
هیچ‌وقت با محتوای کانال‌های دیگر قاطی نشود — حتی دو کانال از «یک» انجمن
هر کدام شماره‌گذاری، صف، آمار و توکن مستقل خودشان را دارند.

## گام‌به‌گام (۵ دقیقه)

۱. **کپی قالب:**
   ```bash
   cp -r _TEMPLATE channels/<نام-انگلیسی-یکتا>
   ```
   نام پوشه (slug) باید انگلیسی، کوچک و یکتا باشد؛ مثال: `robotic`، `web-dev`،
   `coding2` (اگر کانال دومِ همان انجمن کدنویسی باشد).

۲. **شناسنامه:** در `channels/<slug>/channel.json` همهٔ مقادیر را پر کن:
   - `chat_id` → شناسهٔ عددی کانال در بله (بات را ادمین کن، بعد از یک پست
     در کانال مقدارش از `getUpdates` خوانده می‌شود)
   - `handle` و `link` → آیدی و لینک کانال
   - `brand_name` و `footer_label` → همان نامی که روی عکس‌ها می‌نشیند
   - `schedule` → ساعت‌های انتشار همان کانال

۳. **توکن:** در `.env` (خارج از مخزن — هرگز commit نمی‌شود) این خط را اضافه کن:
   ```
   BALE_TOKEN_<SLUG-بزرگ>=توکن-بات-همان-کانال
   ```
   مثال: برای slug برابر `robotic` → `BALE_TOKEN_ROBOTIC=...`

۴. **لوگو (اختیاری):** تصویر لوگوی همان کانال را در
   `channels/<slug>/assets/logo.png` بگذار؛ اگر نباشد نشان متنی می‌نشیند.

۵. **تست:** انتشار آزمایشی بدون ارسال واقعی:
   ```bash
   python3 scripts/roznegar.py --channel <slug> --kind variety --dry
   ```
   اگر خروجی بدون خطا بود، دیمن خودش از این لحظه کانال جدید را در چرخهٔ
   زمان‌بندی می‌گیرد (یا `bash scripts/bootstrap.sh` را اجرا کن).

## ایزولاسیون چیست؟

| چیز مشترک بین کانال‌ها | چیز ایزوله برای هر کانال |
|---|---|
| فونت‌ها، اسکریپت‌ها، شیوه‌نامهٔ مشترک | صف پست‌ها (`queue/`)، آرشیو (`posts/`)، شماره‌گذاری NNN، `state.json`، آمار، تقویم، توکن، لوگو، دسته‌بندی داخلی |
| دیمن واحد روزنگار | هر کانال اسلات‌های زمانی خودش را از channel.json می‌خواند |

شماره‌گذاری پست‌ها (۰۰۱، ۰۰۲، …) **داخل هر کانال جداگانه** است؛
پست ۰۰۱ کانال A هیچ ربطی به پست ۰۰۱ کانال B ندارد و هر دو در پوشهٔ
خودشان آرشیو می‌شوند — هیچ تداخل یا قاطی‌شدنی رخ نمی‌دهد.
