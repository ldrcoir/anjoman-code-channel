# 🖥️ سامانهٔ چندانجمنی بله — تولید، انتشار و مستندسازی محتوا

پروژه تولید، طراحی و انتشار خودکار محتوای کانال‌های انجمن‌های علمی در پیام‌رسان بله،
بر اساس **شیوه‌نامه هفتمین دوره مسابقات کدنویسی جشنواره علمی–پژوهشی پژوهش‌سراهای
دانش‌آموزی** (سال تحصیلی ۱۴۰۳–۱۴۰۴).

- کانال فعلی: انجمن کدنویسی [@anjomanfaghihi](https://ble.ir/anjomanfaghihi) — (تأیید زندهٔ getChat: ۱۴۰۴-۰۷-۲۸؛ ادمین‌ها گاهی آدرس را عوض می‌کنند، روزنگار قبل از هر انتشار کنترل می‌کند)
- سامانهٔ انتشار: **روزنگار v4** (چندانجمنی، مقاوم به ریست سرور)

> **⚠️ تصمیم مالک (۱۴۰۴-۰۷-۲۸):** آموزش زبان کانال = **Rust از صفر** (روزانه ۱۰:۰۰).
> پایتون مال عرشیاست — بات هیچ پست پایتونی نمی‌گذارد. دسته‌بندی فقط داخلی است و
> همهٔ پیام‌های کانال (ما + اعضا) طبق شیوه‌نامه در `channels/coding/content/inventory.md`
> دسته‌بندی می‌شوند. قبل از هر انتشار، آدرس زندهٔ کانال با getChat کنترل می‌شود.

## 🔒 قاعدهٔ طلایی دسته‌بندی

**دسته‌بندی محتوا هرگز روی عکس یا متن پست نوشته نمی‌شود** — نه چیپ، نه خط «دسته»،
نه هشتگِ نام دسته. هشتگ‌ها همیشه موضوعی‌اند (مثل `#چالش_کدنویسی` `#هوش_مصنوعی`).
دسته‌بندی فقط **داخلی** است و از بندهای شیوه‌نامه استخراج می‌شود
(آموزشی/ترویجی/رویداد/معرفی/اطلاعیه/خلاقانه — سند کامل:
[`channels/coding/content/plan.md`](channels/coding/content/plan.md)) و در
`meta.json`، آمار و [`channels/coding/content/inventory.md`](channels/coding/content/inventory.md)
ثبت می‌شود — شامل دسته‌بندی پست‌های خودِ ما و پست‌های بقیهٔ اعضای کانال.

## 🗂️ معماری چندانجمنی — هیچ قاطی‌شدنی در کار نیست

```
├── channels/
│   ├── coding/                    انجمن کدنویسی (@anjomanfaghihi)
│   │   ├── channel.json           شناسنامهٔ کانال (chat_id، آیدی، تقویم، توکن‌کلید)
│   │   ├── content/
│   │   │   ├── plan.md            سند مرجع: دسته‌بندی داخلی + نگاشت شیوه‌نامه + تقویم
│   │   │   ├── inventory.md       فهرست و دسته‌بندی داخلی کل محتوای کانال (ما + اعضا)
│   │   │   ├── state.json         وضعیت انتشار (مقاوم به ریست)
│   │   │   └── stats.md / .json   آمار خودکار
│   │   ├── posts/                 آرشیو پست‌های منتشرشده (شماره‌گذاری اختصاصی همین کانال)
│   │   └── content/queue/         صف انتشار (lessons + variety)
│   └── _TEMPLATE/                 قالب آمادهٔ افزودن انجمن/کانال جدید
├── scripts/                       روزنگار، رندر، آمار، بوت‌استرپ (مشترک بین همهٔ کانال‌ها)
├── assets/fonts/                  فونت وزیرمتن (SIL OFL)
└── docs/                          شیوه‌نامهٔ دورهٔ هفتم (PDF)
```

هر کانال/انجمن **ایزوله کامل** دارد: صف، آرشیو، شماره‌گذاری NNN، state، آمار،
تقویم، توکن و لوگوی خودش را. حتی **دو کانال از یک انجمن** هم دو پوشهٔ جدا می‌گیرند
و هیچ‌وقت با هم قاطی نمی‌شوند. دیمن واحد، همهٔ کانال‌ها را می‌شناسد و هر کدام را
سر اسلات‌های خودش منتشر می‌کند.

**افزودن انجمن جدید (۵ دقیقه):** [`_TEMPLATE/README.md`](_TEMPLATE/README.md)

## ⚙️ انتشار خودکار — مقاوم به ریست سرور

- دیمن **روزنگار v4**: اسلات‌ها از `channel.json` هر کانال خوانده می‌شود
  (درس Rust هر روز ۱۰:۰۰ صبح + پست متنوع ۱۹:۰۰ شنبه/سه‌شنبه/پنج‌شنبه — سقف ۳ پست در روز)
- پیش از هر انتشار، نام‌کاربری زندهٔ کانال با `getChat` گرفته می‌شود؛ اگر ادمین‌ها
  آدرس را عوض کرده باشند، شناسنامهٔ کانال و لینک کپشن خودکار اصلاح می‌شوند
- **state داخل مخزن گیت است**؛ بعد از هر ریست فقط `bash scripts/bootstrap.sh`
  اجرا می‌شود: همگام‌سازی با گیت‌هاب + روشن‌کردن دیمن + جبران خودکار اسلات‌های ازدست‌رفته
- هر انتشار: رندر برند + نسخهٔ clean → بازبینی کیفیت → ارسال → آرشیو با meta.json
  → آمار → commit و push (کامیت‌ها با پیشوند `[<slug>]` تا کانال‌ها در تاریخچه هم تفکیک شوند)

## 🧪 ابزارهای خط فرمان

```bash
python3 scripts/update_stats.py --channel coding                    # بازسازی آمار
bash scripts/bootstrap.sh                                           # پس از هر ریست سرور
python3 scripts/render_all_v4.py coding                             # رندر مجدد همهٔ صف+آرشیو
```
