# پژوهش‌سرای دانش‌آموزی امام هادی (ع) — خانهٔ گیت‌هاب

این مخزن، خانهٔ مرتب همهٔ پرونده‌های پژوهش‌سراست. صفحهٔ اول فقط چهار چیز دارد و بس:

| پوشه | چیست؟ |
|---|---|
| [`EMA/`](EMA/) | بستهٔ تحویل مالک — هر چیزی که برای ایشان ساخته می‌شود فقط همین‌جا |
| [`Karhaye-Man/`](Karhaye-Man/) | دفتر کار دستیار — قانون مالک، کارنامهٔ گردش‌ها، فونت‌ها، اسکلت انجمن‌های آینده |
| [`anjoman-code/`](anjoman-code/) | انجمن کدنویسی — آرشیو کامل کانال + نشریهٔ انجمن |
| [`anjoman-enerjy/`](anjoman-enerjy/) | انجمن انرژی (انرژی‌پژوهان) — آرشیو کامل کانال + نشریهٔ انجمن |

## کانال‌های بله

## قواعد ثابت این مخزن

- هر تحویلی فقط در `EMA/` می‌نشیند؛ هیچ چیز بی‌ربطی به آن راه ندارد.
- آرشیو محتوای هر کانال دست‌نخورده در پوشهٔ همان انجمن نگه داشته می‌شود.
- دو انجمن کاملاً جداهستند: آرشیو، نشریه و هویت هر کدام در پوشهٔ خودش است.
- پروژه‌های اپ و ابزارهای ساخت به این مخزن برنمی‌گردند.
