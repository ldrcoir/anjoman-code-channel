# 🖥️ کانال انجمن کدنویسی — تولید و انتشار محتوا

پروژه تولید، طراحی و انتشار خودکار محتوای کانال «انجمن کدنویسی» در پیام‌رسان بله، بر اساس **شیوه‌نامه هفتمین دوره مسابقات کدنویسی جشنواره علمی–پژوهشی پژوهش‌سراهای دانش‌آموزی** (سال تحصیلی ۱۴۰۳–۱۴۰۴).

- کانال: [@anjomanfaghihi](https://ble.ir/anjomanfaghihi)
- بات ناشر: انجمن کدنویسی مدرسه فقیهی

## 📁 دسته‌بندی محتوای کانال (طبق شیوه‌نامه)

دسته‌بندی فعالیت‌ها عیناً از بند ۳–۲ شیوه‌نامه انجمن کدنویسی (پیوست ۱) و معیارهای «نمون‌برگ ۲ داوری غیرحضوری» استخراج شده است:

| # | دسته | نمونه محتوا | امتیاز داوری |
|---|------|-------------|--------------|
| ۱ | 🚀 فعالیت ترویجی و تولید محتوا | عکس‌نوشته آموزشی، پوستر علمی، تیزر | ۲۰ |
| ۲ | 🎓 فعالیت آموزشی | سمینار، کارگاه آموزشی | ۲۰ |
| ۳ | 🏆 رویدادهای علمی | مسابقه، چالش، استارتاپ، اردو | ۲۰ |
| ۴ | 📚 معرفی کتاب، نشریه و متخصصان | معرفی کتب، دانشمندان رایانه | ۱۰ |
| ۵ | 📢 اطلاعیه و پیام مناسبتی | انتقال اطلاعیه‌های پژوهش‌سرا، انگیزشی | ۱۵ |
| ۶ | 💡 فعالیت خلاقانه و نوآوری | ایده‌های نو و متفاوت | ۱۰ |

هر پست در کپشن با برچسب «📁 دسته‌بندی» و هشتگ‌های همان دسته منتشر می‌شود تا در داوری به‌راحتی قابل ردیابی باشد.

## 🗂️ ساختار پروژه

```
├── assets/fonts/          فونت وزیرمتن (SIL OFL)
├── docs/                  شیوه‌نامه کدنویسی (PDF)
├── posts/                 آرشیو پست‌ها: تصویر + کپشن
│   └── post-01-python/
├── scripts/
│   ├── make_post.py       تولید عکس‌نوشته (Pillow + libraqm، متن فارسی RTL)
│   └── send_post.py       ارسال به کانال با Bale Bot API
└── README.md
```

## ⚙️ راه‌اندازی

```bash
pip install pillow arabic-reshaper
python3 scripts/make_post.py     # تولید تصویر پست
BALE_TOKEN=<توکن بات> python3 scripts/send_post.py   # ارسال به کانال
```

توکن بات در فایل `.env` (خارج از ریپو) نگه‌داری می‌شود و هرگز کامیت نمی‌گردد.

## 🧾 نکته فنی رندر فارسی

Pillow همراه با libraqm شکل‌دهی و جهت‌دهی RTL را خودش انجام می‌دهد؛ بنابراین متن باید **خام و منطقی** با `direction="rtl"` رندر شود. استفاده همزمان از `arabic_reshaper` باعث وارونگی حروف می‌شود (این باگ در نسخه اول پست ۱ رخ داد و با راستی‌آزمایی بصری پیش از انتشار کشف و اصلاح شد).
