# 🖥️ کانال انجمن کدنویسی — تولید و انتشار محتوا

پروژه تولید، طراحی و انتشار خودکار محتوای کانال «انجمن کدنویسی» در پیام‌رسان بله، بر اساس **شیوه‌نامه هفتمین دوره مسابقات کدنویسی جشنواره علمی–پژوهشی پژوهش‌سراهای دانش‌آموزی** (سال تحصیلی ۱۴۰۳–۱۴۰۴).

- کانال: [@anjomanfaghihi](https://ble.ir/anjomanfaghihi)
- بات ناشر: انجمن کدنویسی مدرسه فقیهی

## 📁 دسته‌بندی محتوا — فقط فارسی

دسته‌ها از بند ۳–۲ شیوه‌نامه (پیوست ۱) و معیارهای «نمون‌برگ ۲ داوری غیرحضوری» استخراج شده‌اند.
در کانال فقط **نام فارسی** دسته دیده می‌شود (چیپ رنگی روی عکس + هشتگ فارسی)؛
هیچ کد اختصاری لاتینی (مثل AMOO/MOAR) در کپشن، تصویر یا هشتگ‌ها استفاده نمی‌شود:

| دسته | رنگ چیپ | هشتگ‌ها | امتیاز داوری |
|------|---------|---------|--------------|
| آموزشی | فیروزه‌ای | `#آموزش_پایتون` `#پایتون_از_صفر` | ۲۰ |
| ترویجی | سبز | `#ترویجی` `#کدنویسی_یاد_بگیر` | ۲۰ |
| رویداد | نارنجی | `#رویداد` `#چالش_کدنویسی` | ۲۰ |
| معرفی | بنفش | `#معرفی` `#دانستنی_کدنویسی` | ۱۰ |
| اطلاعیه | طلایی | `#اطلاعیه` `#تقویم_انتشار` | ۱۵ |
| خلاقانه | صورتی | `#خلاقانه` `#ایده_کدنویسی` | ۱۰ |

هشتگ ثابت همه پست‌ها: `#انجمن_کدنویسی` — سند کامل: [`content/plan.md`](content/plan.md)

## 🗂️ ساختار پروژه

```
├── assets/fonts/          فونت وزیرمتن (SIL OFL)
├── content/
│   ├── plan.md            دسته‌بندی فارسی + نگاشت به بندهای شیوه‌نامه + تقویم + چک‌لیست
│   ├── state.json         وضعیت انتشار روزنگار (منبع حقیقتِ واحد = گیت‌هاب)
│   ├── stats.md / stats.json  آمار انتشار (تعداد + تفکیک دسته/سری)
│   └── queue/
│       ├── lessons/       درس‌های «آموزش پایتون از صفر» (نوبت انتشار)
│       └── variety/       پست‌های متنوع (ترویجی/رویداد/معرفی/اطلاعیه/خلاقانه)
├── docs/                  شیوه‌نامه کدنویسی (PDF)
├── posts/                 آرشیو پست‌های منتشرشده (001، 002، …):
│   ├── post.png           تصویر منتشرشده (با نشان انجمن)
│   ├── post-clean.png     نسخه بدون نام/آدرس انجمن (برای استفاده آزاد)
│   ├── text.md            متن کامل فارسی عکس (بایگانی برای فراخوانی بعدی)
│   ├── caption.txt        کپشن + هشتگ‌ها
│   └── meta.json          شناسنامه (شماره، دسته فارسی، درس، message_id، تاریخ)
├── scripts/
│   ├── poster_lib.py      کتابخانه رندر (RTL با Pillow+raqm، چیپ درس و دستهٔ فارسی، توزیع خودکار فضا)
│   ├── roznegar.py        روزنگار: انتشار یک پست از صف + آرشیو + آمار + push
│   ├── roznegar_daemon.py دیمن زمان‌بند (درس ۱۰:۰۰ هر روز | متنوع ۱۹:۰۰ شنبه/سه‌شنبه/پنج‌شنبه)
│   ├── bootstrap.sh       بوت‌استرپ پس از هر ریست سرور (sync + روشن‌کردن دیمن)
│   └── update_stats.py    تولید آمار انتشار
└── README.md
```

## ⚙️ راه‌اندازی پس از هر ریست سرور

```bash
bash scripts/bootstrap.sh
```

این اسکریپت مخزن را با گیت‌هاب همگام می‌کند، دیمن روزنگار را (اگر مرده) روشن می‌کند
و دیمن در شروع، اسلات‌های ازدست‌رفتهٔ امروز را جبران می‌کند.
چون `state.json` داخل همین مخزن است و در گیت‌هاب push می‌شود، هیچ‌چیز تکراری یا
گم‌شده منتشر نمی‌شود.

## 🤖 روزنگار — سامانهٔ انتشار روزانه (بدون نیاز به پیام کاربر)

- ساعت‌ها (تهران): درس پایتون ۱۰:۰۰ هر روز | پست متنوع ۱۹:۰۰ شنبه/سه‌شنبه/پنج‌شنبه — سقف ۳ پست در روز.
- جمعه‌ها استراحت؛ مرور تمرین‌ها و معرفی بهترین پاسخ‌ها.
- هر پست پس از انتشار با `post.png` + `post-clean.png` + `text.md` + `meta.json` آرشیو و push می‌شود.
- آمار زنده: [`content/stats.md`](content/stats.md)

```bash
python3 scripts/roznegar.py --kind lesson  --dry      # رندر بدون ارسال (بازبینی)
python3 scripts/roznegar.py --kind lesson  --force    # انتشار فوری (تست)
python3 scripts/roznegar.py --kind variety            # انتشار پست متنوع بعدی
```

## 📚 سری «آموزش پایتون از صفر» — قاعدهٔ سرِ منحنی

یواش یواش، قدم‌به‌قدم، با مثال زیاد؛ هر درس فقط یک مفهوم کوچک + ۳–۴ مثال حل‌شده + تمرین:

۱. پایتون چیست و چرا؟ → ۲. نصب و اولین اجرا → ۳. print با متن → ۴. print با اعداد
→ ۵. کامنت و خطاها → ۶. متغیرها (۱) → ۷. متغیرها (۲) و نام‌گذاری → ۸. int و float
→ ۹. رشته‌ها → ۱۰. bool → ۱۱. تبدیل نوع → ۱۲. input → ۱۳. f-string → ۱۴. عملگرها
→ ۱۵. عملگرهای ویژه → ۱۶. جمع‌بندی و پروژه کوچک → سپس شرط if و ادامه مسیر.
