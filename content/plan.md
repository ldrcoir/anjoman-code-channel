## ۳) قواعد شماره‌گذاری و آرشیو

- هر پست یک شماره سه‌رقمی جهانی دارد: `001`، `002`، …
- ساختار آرشیو:

```
posts/
└── 001-python-lesson-01/
    ├── python-post-01.png   ← تصویر نهایی منتشرشده
    ├── caption.txt          ← متن کپشن + هشتگ‌ها (همان متن ارسالی)
    └── meta.json            ← شناسنامه پست
```

- قالب `meta.json`:

```json
{
  "number": 1,
  "code": "001",
  "category": "TROJ",
  "series": "python",
  "part": 1,
  "title": "اولین برنامه‌ات را بنویس!",
  "date": "2026-10-18",
  "message_id": null,
  "image": "python-post-01.png"
}
```

- `message_id` پس از انتشار از پاسخ API ثبت می‌شود تا ردیابی پست در کانال ممکن باشد.

## ۵) چک‌لیست انتشار هر پست

1. دسته را از جدول بالا انتخاب کن؛ کد دسته و شماره سه‌رقمی را تعیین کن.
2. تصویر را با `scripts/make_post.py` تولید و **قبل از ارسال با دید حضوری بازبینی کن** (متن فارسی، تراز راست، خوانایی متن‌های پایین).
3. کپشن شامل: عنوان + بدنه آموزشی/خبری + تمرین یا دعوت به مشارکت + لینک کانال `ble.ir/anjomanfaghihi` + هشتگ‌های دسته و موضوع.
4. ارسال با `scripts/send_post.py` و ثبت `message_id` در `meta.json`.
5. commit و push روی همین ریپو (آرشیو پایدار).

## ۶) انتشار خودکار روزانه (بدون دخالت دستی)

کانال هر روز ساعت **۱۹:۰۰ به‌وقت تهران** به‌صورت خودکار پست می‌گذارد:

```
content/queue/NNN-slug/spec.py      ← طراحی تصویر (با poster_lib)
content/queue/NNN-slug/caption.txt  ← متن کپشن + هشتگ‌ها
        │  scheduler_daemon.py (هر روز ۱۹:۰۰ تهران)
        ▼
auto_publish.py:  رندر → ارسال به کانال → meta.json → انتقال به posts/ → commit/push
```

- هر روز فقط **یک** پست (قدیمی‌ترین آیتم صف) منتشر می‌شود؛ اجرای موازی با قفل فایلی مسدود است.
- آرشیو هر پست پس از انتشار با `message_id` واقعی در `posts/NNN-slug/` ثبت و push می‌شود.
- **پر کردن صف:** کافی است پوشه جدیدی مثل `content/queue/009-…/` با `spec.py` و `caption.txt` ساخته شود؛ بقیه‌اش خودکار است.
- ثبت‌نام‌های رسمی و اطلاعیه‌های فوری می‌توانند جدا از صف، دستی منتشر شوند (`send_post.py`).
