# زندگی، مثل یک کد
نگاه خلاقانه به کدنویسی

تلاش کن، یاد بگیر، ادامه بده

فایل «main.py»:
```python
try:            # تلاش کن
    start()
except Error:     # خطا گرفتی؟
    learn()       # یاد بگیر
finally:        # در هر صورت
    continue()  # ادامه بده
```

- **خطا = درس**: هر exception یک فرصت یادگیری است
- **ادامه = کلید**: برنامه‌نویس واقعی از finally نمی‌ترسد

نکته: سینتکس واقعی پایتون — بعداً در درس‌های پیشرفته کاملش را می‌خوانیم

دستهٔ محتوا: خلاقانه
