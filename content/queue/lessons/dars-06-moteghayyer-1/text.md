# متغیرها (بخش ۱)
آموزش پایتون از صفر — درس ۶

جعبه‌ای با نام برای نگه‌داری داده

فایل «main.py»:
```python
name = "سارا"      # جعبهٔ نام
age = 15          # جعبهٔ سن
# ──── خروجی برنامه ────
print(name)
print(age)
سارا
15
```

- **علامت =**: یعنی مقدارِ سمت راست را در جعبه بگذار
- **صدا زدن**: هرجا نام جعبه باشد، محتوایش استفاده می‌شود

نکته: دقت: علامت = مثل ریاضی «برابری» نیست؛ «انتساب» است

دستهٔ محتوا: آموزشی
