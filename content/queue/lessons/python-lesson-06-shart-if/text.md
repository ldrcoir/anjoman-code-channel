# تصمیم‌گیری با if
آموزش پایتون از صفر — درس ۶

حالا که متغیر و عملگر را بلدی، برنامه‌ات فکر کند!

فایل «shart.py»:
```python
score = 16
if score >= 10:
    print("قبول شدی!")
else:
    print("تمرین بیشتر!")
# ──── مثال ۲ — چند شرط با elif ────
temp = 35
if temp > 30:
    print("هوا گرم است")
elif temp > 15:
    print("هوا معتدل است")
else:
    print("هوا سرد است")
```

نکته: تورفتگی ۴ فاصله‌ای اجباری است؛ پایتون بلوک را از تورفتگی می‌فهمد
