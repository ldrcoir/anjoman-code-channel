# انواع داده در پایتون
آموزش پایتون از صفر — درس ۳

هر داده یک نوع دارد؛ با type() آن را ببین

فایل «types.py»:
```python
age = 15            # int
price = 99.5         # float
name = "سارا"      # str
ok = True           # bool
print(type(age))  # <class 'int'>
```

- **int**: اعداد صحیح؛ مثل 15
- **float**: اعداد اعشاری؛ مثل 99.5
- **str**: متن؛ میان گیومه می‌نشیند
- **bool**: منطقی؛ True یا False

نکته: تبدیل نوع: int() و float() و str() — مثلا int("12") + 3 می‌شود 15
