# خروجی و ورودی
آموزش پایتون از صفر — درس ۴

با print نشان بده، با input بپرس

فایل «talk.py»:
```python
name = input("اسمت چیه؟ ")
print("سلام", name)
# ──── مثال ۲ — نوشتن مرتب با f-string ────
age = 15
print(f"سن تو {age} سال است")
# ──── مثال ۳ — گرفتن عدد از کاربر ────
n = int(input("یک عدد بگو: "))
print(n * 2)
```

- **تابع input()**: همیشه متن (str) می‌دهد؛ برای عدد از int() کمک بگیر
- **f-string**: میان f"..." هر متغیری را داخل { } بگذار تا چاپ شود
