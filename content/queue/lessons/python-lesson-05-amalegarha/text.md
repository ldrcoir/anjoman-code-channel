# عملگرها در پایتون
آموزش پایتون از صفر — درس ۵

ابزارهای محاسبه و مقایسه

فایل «operators.py»:
```python
print(7 + 3)      # 10
print(7 % 3)      # 1  باقیمانده
print(2 ** 4)     # 16 توان
print(10 >= 9)    # True
print(True and False)  # False
```

- **حسابی**: +  -  *  /  //  %  **
- **مقایسه‌ای**: ==  !=  >  <  >=  <=
- **منطقی**: and  or  not
- **انتساب**: =  +=  -=  خلاصه‌نویسی

نکته: ترتیب اجرا مثل ریاضی است؛ پرانتز اولویت را عوض می‌کند
