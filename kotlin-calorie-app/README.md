# کالری‌یار 🥗

اپ کالری‌شمار، آب‌شمار و دستیار هوشمند رژیم برای دانش‌آموزها و خانواده‌ها — ساخته‌شده برای **انجمن کدنویسی مدرسهٔ شهید فقیهی**.

## ویژگی‌ها (تحلیل بهترین‌های کرفس/کارا/مانکن + MyFitnessPal/Yazio/Cal AI)

| بخش | توضیح |
| --- | --- |
| ورود اطلاعات اولیه | جنسیت، سن، قد، وزن، سطح فعالیت، هدف → محاسبهٔ BMR با فرمول میفلین-سنت‌جیور + TDEE + کالری هدف با کف ایمن |
| داشبورد | حلقهٔ کالری باقی‌مانده (نمای سفارشی)، نوارهای پروتئین/کربوهیدرات/چربی، استریک روزهای پیوسته |
| پایگاه غذا | ۱۶۰+ خوراکی ایرانی و رایج با کالری و ریزمغذی هر ۱۰۰ گرم + سهم رایج + نمرهٔ سلامت A تا E |
| دفترچهٔ روزانه | ۴ وعده (صبحانه/ناهار/شام/میان‌وعده)، پیش‌نمایش زندهٔ کالری هنگام ثبت، حذف ردیف |
| آب‌شمار | هدف بر اساس وزن (۳۵ میلی‌لیتر به‌ازای هر کیلو)، لیوان ۲۵۰ میلی‌لیتری، حلقهٔ پیشرفت |
| ورزش | ۱۴ فعالیت با فرمول MET؛ کالری سوزانده به بودجهٔ خوراک اضافه می‌شود |
| وزن و BMI | ثبت وزن، نمودار خطی روند، BMI و توصیف، تخمین روز رسیدن به هدف با سرعت ایمن |
| گزارش هفته | نمودار میله‌ای ۷ روز با خط هدف، میانگین، تحلیل هوشمند هفتگی |
| دستیار هوشمند | موتور متخصص آفلاین: تشخیص نیت سؤال فارسی، جست‌وجوی فازی غذا، «الان چی بخورم؟» بر اساس کالری/پروتئین باقی‌مانده، تحلیل روز و هفته |

**دستیار هوشمند کاملاً آفلاین است** — بدون اینترنت، بدون سرور، بدون اشتراک؛ حریم خصوصی کامل: هیچ داده‌ای از گوشی بیرون نمی‌رود.

## فناوری

همه‌چیز با کاتلین خالص و سیستم View اندروید؛ بدون Jetpack Compose، بدون کتابخانهٔ بیرونی، بدون مجوز خاص. رابط کاربری کاملاً فارسی و راست‌چین با فونت وزیرمتن. داده‌ها با SharedPreferences + JSON ذخیره می‌شوند.

## ساخت

APK با GitHub Actions (`.github/workflows/build-calorie-apk.yml`) ساخته می‌شود: `gradle assembleDebug` با JDK 17 و Gradle 8.5.
