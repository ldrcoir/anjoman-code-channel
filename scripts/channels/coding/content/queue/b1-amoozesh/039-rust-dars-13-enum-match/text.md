# شمارشی‌ها و match
آموزش Rust از صفر — درس ۱۳
انجمن کدنویسی | مدرسهٔ شهید فقیهی

وقتی مقدار فقط یکی از چند حالت می‌تواند باشد

فایل «src/main.rs»:
```rust
enum Cheragh { Roshan, Khamoosh }

fn main() {
    let cheragh = Cheragh::Roshan;

    match cheragh {
        Cheragh::Roshan => println!("roshan ast!"),
        Cheragh::Khamoosh => println!("khamoosh."),
    }
}
# ──── خروجی ────
roshan ast!
```

- **enum**: فهرست حالت‌های ممکنِ یک مقدار — مثل روشن/خاموش
- **match**: تابلو برق چندتایی: هر حالت با یک شاخه، هر شاخه کارِ خودش
- **حالتِ جامانده؟**: کامپایلر خطا می‌دهد و بیلد نمی‌شود — هیچ حالتی از قلم نمی‌افتد

نکته: تمرین: enumی برای فصل‌های سال بساز و با match برای هر فصل یک یادگاری چاپ کن — بهار: باران و شکوفه، زمستان: برف و نارنج!
