# کتابچهٔ صندوق پس‌انداز (KetabcheSandogh)

اپ اندرویدیِ کتابچه‌وار برای «وضعیت صندوق پس‌انداز» — ساخته‌شده از فایل PDF کتابچه (مهر ۱۴۰۵) به دستور مالک (گردش ۵۳).

## امکانات
- **جلد** با قاب طلایی و انیمیشن ورود
- **فهرست مطالب** ۶ فصل + کارت خلاصهٔ صندوق
- **خواناک ورق‌خور**: انیمیشن سه‌بعدی ورق‌زدن (کشیدن انگشت یا دکمه) + نقطه‌های جای‌نما
  1. شناسنامهٔ صندوق — کارت‌های جمع‌کل (یورو/دلار/سکه/تتر/USDC/دای…) + کارت بزرگ پس‌انداز تومانی
  2. تسویهٔ دلار اعضا — جدول کامل ۳۰ عضو با جست‌وجوی زنده و ردیف مجموع
  3. سهم و پس‌انداز — نمودار دایره‌ای سهم درصدی + نوارهای پس‌انداز تومانی
  4. تسویهٔ ارز دیجیتال و دلار — هر عضو چقدر تسویه شده
  5. تتر خریداری‌شده از سایرین — یادداشت قرمز کتابچه (مجموع ۷۵٫۲۰)
  6. راهنمای کتابچه — معنای همهٔ ستون‌ها
- **۴ تم**: شب فیروزه‌ای، کلاسیک طلایی، سبز بانکی، بنفش کهکشانی — ذخیره در گوشی
- فونت وزیرمتن، اعداد فارسی، کاملاً آفلاین، **بدون هیچ مجوزی**

## حریم خصوصی داده
دادهٔ مالی خانوادگی داخل `assets/ledger.json` فقط در زمان ساخت تزریق می‌شود و **در ریپو نیست**:
- سورسِ در ریپو فایل داده ندارد (اپ بدون داده هم بدون کرش باز می‌شود و پیام «داده‌ای نیست» می‌دهد)
- در اکشنز، Secrets به‌نام `SANDOGH_LEDGER` (base64 فایل JSON) در مرحلهٔ بیلد به `assets/ledger.json` تبدیل می‌شود
- APK فقط به‌صورت **Artifact خصوصی** از Actions دانلود می‌شود؛ **Release عمومی ندارد**

## ساخت
پوش `kotlin-sandogh-app/**` → ورک‌فلو `build-sandogh-apk.yml` با JDK 17 / Gradle 8.5 / AGP 8.2.2 / Kotlin 1.9.24
