# آموزش Rust — اپ انجمن کدنویسی (EmaRoid)

اپ آموزشی Rust برای بچه‌های **انجمن کدنویسی** — همان ۱۲ درسِ کانال، این بار روی گوشی.
از قالب «آموزش کاتلین» ساخته شده با تم نارنجیِ گرمِ راست.

- ۱۲ درس از «Rust چیست؟» تا «سازه‌ها» + آزمون سه‌سؤالی هر درس
- درس بدون اسکرول: صفحه‌به‌صفحه با دکمهٔ بعد/قبل + پس‌زمینهٔ طرح‌دار
- چندزبانه: فارسی / English (پرچم ایرلند) / العربية (پرچم فلسطین)
- آمارگیر بی‌صدای EmaRoid (فقط مجوز INTERNET) + تبلیغ خانه
- برند درباره: **EmaRoid**

ساخت release: فایل‌های کلید را در `enteshar/` بگذار (ببین `enteshar/README.md`)، سپس:
`gradle assembleRelease`
