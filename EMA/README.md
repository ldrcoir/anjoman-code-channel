نشریه‌های قبلی از گیت‌هاب پاک شدند (حتی از تاریخچهٔ گیت) و هر سه از نو نوشته شدند:

| `nashriye-ha/majale-enerjy-novin-aban1405.pdf` + `.docx` | مجلهٔ انرژی‌های نوین — ویژهٔ آبان ۱۴۰۵ (۱۰ صفحه؛ پنج پرونده + نمودار + دو پروژهٔ اسکرچ) |

- برند فقط **پژوهش‌سرا** (و نام کامل «پژوهش‌سرای دانش‌آموزی امام هادی (ع)») — هیچ نام دیگری در هیچ‌کجا نیست.
- در نشریه‌ها **صفر اشاره به اپ** است — طبق فرمان تو، اپ‌ها به چت دیگر رفتند.
- نسخهٔ Word راست‌چین و رنگی است: سربرگ‌های رنگی، جدول‌های رنگی، کارت‌های آمار، جعبه‌های کدِ تیره و تصویرها داخل خودِ ورد.
- هر عدد و نشانی از بایگانی واقعی دو کانال (مهر و آبان ۱۴۰۵) آمده: ساتبا، وزارت نیرو، `ble.ir/anjomanfaghihi` و `ble.ir/anjoman_energypazhohan`.
