درس ۱۴ — بردار (Vec) و پروژهٔ کوچک: فهرست کارها
مسیر Rust از صفر · پژوهش‌سرا · پژوهش‌سرای دانش‌آموزی امام هادی (ع)

آرایه را یادت هست؟ طولش از اول ثابت بود. ولی فهرست خرید تو هر روز عوض می‌شود؛ یکی اضافه می‌شود، یکی خط می‌خورد. اینجا بردار (Vec) به کمکمان می‌آید: لیستی که نفس می‌کشد — با push بزرگ می‌شود، اندازه‌اش هر چقدر که لازم باشد.

چون قرار است وسط برنامه عوضش کنیم، کنار let کلمهٔ mut می‌گذاریم؛ مخفف mutable یعنی «این جعبه قرار است تغییر کند». با Vec::new() بردار تازه می‌سازیم، با push عضو اضافه می‌کنیم و با len طولش را می‌پرسیم؛ بعد با همان for درس‌های قبل روی همهٔ اعضایش قدم می‌زنیم.

و حالا پروژهٔ کوچکِ آخر مسیر: سازهٔ کار (Kar) از درس ۱۲ + بردار = «فهرست کارها»! کار اضافه کن، انجام‌شده‌ها را علامت بزن، همه را چاپ کن. اگر همین برنامهٔ کوچک را خودت بنویسی، یعنی از درس ۱ تا ۱۴ را واقعاً یاد گرفته‌ای — منتظر نتیجه‌اش در کانال هستیم!

— کد درس —

struct Kar {
    onvan: String,
    anjamShod: bool,
}

fn main() {
    let mut list: Vec<Kar> = Vec::new();

    list.push(Kar {
        onvan: String::from("tamrin-e rust"),
        anjamShod: false,
    });
    list.push(Kar {
        onvan: String::from("khandan-e dars 14"),
        anjamShod: true,
    });

    println!("tedad-e karha: {}", list.len());

    for kar in list {
        if kar.anjamShod {
            println!("[x] {}", kar.onvan);
        } else {
            println!("[ ] {}", kar.onvan);
        }
    }
}

— آزمون —

1. فرق Vec با آرایه چیست؟
   ا) طول Vec عوض می‌شود؛ آرایه ثابت است
   ل) Vec فقط متن نگه می‌دارد
   ف) آرایه فقط عدد می‌گیرد
   ب) فرقی ندارند
   پاسخ درست: الف

2. به بردار چطور عضو اضافه می‌کنیم؟
   ا) با push
   ل) با add
   ف) با plus
   ب) با give
   پاسخ درست: الف

3. چرا کنار let کلمهٔ mut می‌گذاریم؟
   ا) چون قرار است مقدارش وسط برنامه عوض شود
   ل) چون Rust خیلی دوستش دارد
   ف) برای سریع‌تر شدن
   ب) لازم نیست؛ فقط قشنگ است
   پاسخ درست: الف

— تمرین —

برنامهٔ «فهرست کارها» را خودت از اول بنویس و خروجی‌اش را در کانال بفرست.
