درس ۱۴ — بردار (Vec) و پروژهٔ کوچک: فهرست کارها
مسیر Rust از صفر · پژوهش‌سرا · پژوهش‌سرای دانش‌آموزی امام هادی (ع)

آرایه را یادت هست؟ طولش از اول ثابت بود. ولی فهرست خرید تو هر روز عوض می‌شود؛ یکی اضافه می‌شود، یکی خط می‌خورد. اینجا بردار (Vec) به کمکمان می‌آید: لیستی که با push بزرگ می‌شود و اندازه‌اش هر چقدر که لازم باشد.

چون قرار است وسط برنامه عوضش کنیم، کنار let کلمهٔ mut می‌گذاریم؛ یعنی این جعبه قرار است تغییر کند. با Vec::new() بردار تازه می‌سازیم، با push عضو اضافه می‌کنیم، با len طولش را می‌پرسیم و با همان for درس‌های قبل روی همهٔ اعضایش قدم می‌زنیم.

نکتهٔ طلایی: آرایه طول ثابت دارد ولی بردار در جا بزرگ می‌شود. هر جا قرار است فهرست وسط کار اضافه یا کم شود، از اول Vec با mut بساز.

و حالا پروژهٔ کوچکِ آخر مسیر: سازهٔ کار (Kar) از درس ۱۲ + بردار = «فهرست کارها»! کار اضافه کن، انجام‌شده‌ها را علامت بزن، همه را چاپ کن.

— کد درس —

struct Kar {
    onvan: String,
    anjamShod: bool,
}

fn main() {
    let mut list: Vec<Kar> = Vec::new();

    list.push(Kar {
        onvan: String::from("tamrin-e rust"),
        anjamShod: false,
    });
    list.push(Kar {
        onvan: String::from("khandan-e dars 14"),
        anjamShod: true,
    });

    println!("tedad-e karha: {}", list.len());

    for kar in list {
        if kar.anjamShod {
            println!("[x] {}", kar.onvan);
        } else {
            println!("[ ] {}", kar.onvan);
        }
    }
}

خروجی:
tedad-e karha: 2
[ ] tamrin-e rust
[x] khandan-e dars 14

— آزمون —

۱. فرق Vec با آرایه چیست؟
   الف) Vec فقط متن نگه می‌دارد
   ب) فرقی ندارند
   ج) آرایه فقط عدد می‌گیرد
   د) طول Vec عوض می‌شود؛ آرایه ثابت است
   پاسخ: د

۲. به بردار چطور عضو اضافه می‌کنیم؟
   الف) با add
   ب) با push
   ج) با plus
   د) با give
   پاسخ: ب

۳. چرا کنار let کلمهٔ mut می‌گذاریم؟
   الف) برای سریع‌تر شدن
   ب) لازم نیست؛ فقط قشنگ است
   ج) چون Rust خیلی دوستش دارد
   د) چون قرار است مقدارش وسط برنامه عوض شود
   پاسخ: د

— تمرین —

برنامهٔ «فهرست کارها» را خودت از اول بنویس و خروجی‌اش را در کانال بفرست. اگر بنویسیش، یعنی از درس ۱ تا ۱۴ را واقعاً یاد گرفته‌ای.
