پژوهش‌سرامسیر Rust از صفردرس ۱۴ از ۱۴

بردار (Vec)
و پروژهٔ «فهرست کارها»

فهرستی که نفس می‌کشد — و ساختهٔ کوچک آخرِ مسیر

آرایه را یادت هست؟ طولش از اول ثابت بود. ولی فهرست خرید تو هر روز عوض می‌شود؛ یکی اضافه می‌شود، یکی خط می‌خورد. اینجا بردار (Vec) به کمکمان می‌آید: لیستی که با push بزرگ می‌شود و اندازه‌اش هر چقدر که لازم باشد.

Vec::new() + push
بردار تازه بساز و بزرگش کن
کلیدواژهٔ mut
جعبه‌ای که قرار است تغییر کند
for + len
پیمایش اعضا و پرسیدن طول
پروژهٔ «فهرست کارها» — سازهٔ درس ۱۲ + بردار
struct Kar {
    onvan: String,
    anjamShod: bool,
}

fn main() {
    let mut list: Vec<Kar> = Vec::new();

    list.push(Kar {{
        onvan: String::from("tamrin-e rust"),
        anjamShod: false,
    }});
    list.push(Kar {{
        onvan: String::from("khandan-e dars 14"),
        anjamShod: true,
    }});

    println!("tedad-e karha: {{}}", list.len());

    for kar in list {{
        if kar.anjamShod {{
            println!("[x] {{}}", kar.onvan);
        }} else {{
            println!("[ ] {{}}", kar.onvan);
        }}
    }}
}}
خروجی برنامه:tedad-e karha: 2
[ ] tamrin-e rust
[x] khandan-e dars 14
نکتهٔ طلایی
آرایه طول ثابت دارد ولی بردار در جا بزرگ می‌شود. هر جا قرار است فهرست وسط کار اضافه یا کم شود، از اول Vec با mut بساز.

● آزمون سریع

۱. فرق Vec با آرایه چیست؟
الف) Vec فقط متن نگه می‌دارد    ب) فرقی ندارند
ج) آرایه فقط عدد می‌گیرد    د) طول Vec عوض می‌شود؛ آرایه ثابت است
۲. به بردار چطور عضو اضافه می‌کنیم؟
الف) با add    ب) با push    ج) با plus    د) با give
۳. چرا کنار let کلمهٔ mut می‌گذاریم؟
الف) برای سریع‌تر شدن    ب) لازم نیست؛ فقط قشنگ است
ج) چون Rust خیلی دوستش دارد    د) چون قرار است مقدارش وسط برنامه عوض شود
پاسخ‌ها: ۱) د  ·  ۲) ب  ·  ۳) د
