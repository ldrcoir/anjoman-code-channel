درس ۱۳ — شمارشی‌ها (enum) و تطبیق الگو با match
مسیر Rust از صفر · پژوهش‌سرا · پژوهش‌سرای دانش‌آموزی امام هادی (ع)

تا حالا متغیرهایمان عدد و متن بودند؛ ولی دنیای واقعی «حالت» هم دارد: چراغ یا روشن است یا خاموش، بازی یا برنده است یا بازنده. برای همین Rust قالبی به نام enum می‌دهد: جایی که با هم توافق می‌کنید این مقدار فقط یکی از همین چند حالت را می‌تواند باشد.

همنشین enum کلیدواژهٔ match است: مثل تابلوی برقی که برای هر کلید یک مسیر دارد. هر حالت را می‌گیری و برایش کارِ خودش را انجام می‌دهی؛ اگر حالتی را جا بیندازی، برنامه اصلاً ساخته نمی‌شود.

نکتهٔ طلایی: کامپایلر مواظب توست. اگر یک حالت را در match جا بیندازی، Rust اجازه نمی‌دهد برنامه ساخته شود؛ یعنی باگِ «حالتِ فراموش‌شده» قبل از رسیدن به دست کاربر گرفته می‌شود.

enum و match همه‌جای Rust هستند؛ حتی مدیریت خطا با همین دو کار می‌کند.

— کد درس —

enum Cheragh {
    Roshan,
    Khamoosh,
}

fn main() {
    let cheragh = Cheragh::Roshan;

    match cheragh {
        Cheragh::Roshan => println!("Roshan!"),
        Cheragh::Khamoosh => println!("Khamoosh."),
    }
}

خروجی: Roshan!

— آزمون —

۱. enum برای چیست؟
   الف) تکرار کد
   ب) وقتی مقدار فقط می‌تواند یکی از چند حالت مشخص باشد
   ج) نگه‌داشتن فهرست خرید
   د) پاک کردن حافظه
   پاسخ: ب

۲. اگر در match یکی از حالت‌ها را جا بیندازیم چه می‌شود؟
   الف) کامپایل خطا می‌دهد و برنامه ساخته نمی‌شود
   ب) برنامه همان را نادیده می‌گیرد
   ج) کامپایلر حدس می‌زند
   د) هیچ اتفاقی نمی‌افتد
   پاسخ: الف

۳. match چه‌طور کار می‌کند؟
   الف) همیشه اولین شاخه را اجرا می‌کند
   ب) فقط با عدد کار می‌کند
   ج) هر حالت را با شاخه‌هایش مقایسه می‌کند و کارِ همان شاخه را می‌کند
   د) متن را پاک می‌کند
   پاسخ: ج

— تمرین —

enumی برای فصل‌های سال بساز و با match برای هر فصل یک یادگاری چاپ کن — بهار: باران و شکوفه؛ زمستان: برف و نارنج. خروجی‌اش را در کانال بفرست.
