درس ۱۳ — شمارشی‌ها (enum) و تطبیق الگو با match
مسیر Rust از صفر · پژوهش‌سرا · پژوهش‌سرای دانش‌آموزی امام هادی (ع)

تا حالا متغیرهایمان عدد و متن بودند؛ ولی دنیای واقعی «حالت» هم دارد: چراغ یا روشن است یا خاموش، بازی یا برنده است یا بازنده، روز هفته یا شنبه است یا چهارشنبه. برای همین داده‌های Rust ابزار قشنگی دارد: enum (شمارشی) — قالبی که می‌گویی «این مقدار فقط یکی از این چند حالت را می‌تواند باشد».

همنشین enum کلیدواژهٔ match است: مثل تابلوی برق چندتایی، هر حالت را می‌گیری و برایش کارِ خودش را می‌کنی. نکتهٔ طلایی: کامپایلر مواظب توست — اگر یک حالت را جا بیندازی، برنامه اصلاً ساخته نمی‌شود! یعنی Rust اجازه نمی‌دهد حالتی از قلم بیفتد و بعداً وسط کارِ کاربر سرکش کند.

enum و match همه‌جای Rust هستند؛ حتی مدیریت خطا با همین دو کار می‌کند. تمرین: enumی برای فصل‌های سال بساز و با match برای هر فصل یک یادگاری چاپ کن — بهار: باران و شکوفه، زمستان: برف و نارنج!

— کد درس —

enum Cheragh {
    Roshan,
    Khamoosh,
}

fn main() {
    let cheragh = Cheragh::Roshan;

    match cheragh {
        Cheragh::Roshan => println!("Roshan!"),
        Cheragh::Khamoosh => println!("Khamoosh."),
    }
}

— آزمون —

1. enum برای چیست؟
   ا) وقتی مقدار فقط می‌تواند یکی از چند حالت مشخص باشد
   ل) نگه‌داشتن فهرست خرید
   ف) تکرار کد
   ب) پاک کردن حافظه
   پاسخ درست: الف

2. اگر در match یکی از حالت‌ها را جا بیندازیم چه می‌شود؟
   ا) کامپایل خطا می‌دهد و برنامه ساخته نمی‌شود
   ل) برنامه همان را نادیده می‌گیرد
   ف) کامپایلر حدس می‌زند
   ب) هیچ اتفاقی نمی‌افتد
   پاسخ درست: الف

3. match چه‌طور کار می‌کند؟
   ا) هر حالت را با یک شاخه مقایسه می‌کند و کارِ همان شاخه را می‌کند
   ل) همیشه اولین شاخه را اجرا می‌کند
   ف) فقط با عدد کار می‌کند
   ب) متن را پاک می‌کند
   پاسخ درست: الف

— تمرین —
