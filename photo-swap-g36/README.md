# بستهٔ تعویض عکس — گردش ۳۶ (۱۴۰۵-۰۸-۰۶)

دستور مالک: «در پست‌های کانال انرژی‌های نوین فقط عکس‌ها را ویرایش کن؛ هر جا نوشته ششمین حذف شود؛ اسم پژوهش‌سرا به‌طور کامل بیاید.»

## چه شد؟
- «ششمین» فقط روی سربرگ پوسترهای موتور انرژی بود: خط دوم سربرگ = «ششمین دورهٔ مسابقات انرژی‌های نوین».
- موتور (`scripts/enerjy_poster.py`) اصلاح شد → از این پس سربرگ همهٔ پوسترهای تازه: **پژوهش‌سرای دانش‌آموزی امام هادی (ع)**
- پنج پوسترِ داخل کانال این سربرگ را داشتند و تصویر درست‌شدهٔ هر کدام در همین پوشه است.

## چرا بات خودش عوض نکرد؟
Bot API بله هنوز `editMessageMedia` ندارد (پاسخ سرور: ۵۰۱ «Not Implemented (Coming soon...)»).
تنها راهِ بات حذف و ارسال دوباره است که جای پست را عوض می‌کند — مالک صریحاً ممنوع کرده.
پس دو راه فقط با دستور مالک:
1) **تعویض دستی از اپ بله** (ویرایش پست → تعویض عکس) با همین فایل‌ها — ترتیب پست‌ها دست نمی‌خورد.
2) **اجازهٔ حذف + انتشار مجدد** — در این صورت پست‌ها به انتهای کانال می‌روند (خلاف خواست فعلی مالک).

پیام‌های ۸ (فاطمیه)، ۹ (عکس خورشیدی ادمین) و ۱۰ (بنر «پنجمین دوره») اصلاً «ششمین» ندارند — دست نخوردند.
کپشن‌ها «ششمین» ندارند؛ نیازی به تغییر کپشن نیست.
