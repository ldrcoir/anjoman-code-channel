# نمونه سوال «سبک المپیاد رایانه‌ای» با سطح پایین‌تر — برای چالش کانال انجمن کدنویسی

> **گردش ۲۲ (۱۴۰۵-۰۸-۰۲)** — به درخواست مالک: «تفکر الگوریتمی این‌ها نیست، پاک کن؛
> حالت المپیاد کامپیوتر با سطح پایین‌تر.»
> منابع درسی/کتابیِ پیشین (گاما، کانون، کتاب کار و فناوری و…) کنار گذاشته شد.
> این سند جایگزین آن است: سوال‌ها به **سبک مرحلهٔ اول المپیاد رایانه‌ای ایران**
> (آزمون کتبیِ بدون رایانه) طراحی شده‌اند ولی یک پله آسان‌تر، برای دانش‌آموزانی که
> تازه با درس‌های «Rust از صفر» کانال آشنا شده‌اند.
>
> **سبکِ المپیاد یعنی چه؟** سوال‌هایی که نه حل تمرین کتاب‌اند نه حفظ تعریف؛ بلکه:
> «این کد چه چاپ می‌کند؟»، «چند بار اجرا می‌شود؟»، «جای خالی را کامل کن»،
> «با منطق و شمارش حل کن» — همان چهار قالب اصلی مرحلهٔ اول المپیاد رایانه‌ای.
>
> **سطح پایین‌تر یعنی چه؟** اعداد کوچک (زیر ۱۰)، حلقه‌های حداکثر ۵ دوری، بدون
> ترکیبیات سنگین و بدون سوالِ گراف؛ قابل‌حل با خودکار و کاغذ در ۲ تا ۵ دقیقه.
>
> کدها عمداً با **Rust** نوشته شده‌اند تا با درس‌های کانال (println!، let و mut،
> حلقه‌ها) هم‌خوان باشند — قالب‌ها با شبه‌کد هر زبان دیگری هم قابل استفاده‌اند.

## دستهٔ الف — «خروجی این برنامه چیست؟» (قالب اصلی مرحلهٔ اول)

### سوال ۱ — توالی ساده ★
```rust
let mut x = 5;
x = x + 3;
x = x * 2;
println!("{}", x);
```
خروجی چیست؟

**پاسخ: ۱۶.** — «۱۶.» از ۵ شروع می‌کنیم؛ اول ۳ اضافه می‌شود (۸)، بعد در ۲ ضرب می‌شود (۱۶). دامِ سوال ترتیب عملیات است: اگر کسی اول ضرب کند به ۱۳ می‌رسد که اشتباه است؛ هر خط جداگانه و به‌ترتیب اجرا می‌شود.

### سوال ۲ — باقیمانده و شرط ★★
```rust
let a = 7;
let b = 3;
if a % b == 1 {
    println!("{}", a - b);
} else {
    println!("{}", a + b);
}
```
خروجی چیست؟

**پاسخ: ۴.** — باقیماندهٔ تقسیم ۷ بر ۳ برابر ۱ است (۷ = ۲×۳ + ۱)؛ پس شرط درست است و شاخهٔ اول اجرا می‌شود: ۷ منهای ۳ می‌شود ۴. مفهومی که می‌سنجد: عملگر `%` که در درس‌های آیندهٔ کانال هم می‌آید.

### سوال ۳ — حلقهٔ جمع ★★
```rust
let mut s = 0;
let mut i = 1;
while i <= 4 {
    s = s + i;
    i = i + 1;
}
println!("{}", s);
```
خروجی چیست؟

**پاسخ: ۱۰.** — حلقه چهار دور می‌زند و به ترتیب ۱ و ۲ و ۳ و ۴ را به جمع اضافه می‌کند: ۱+۲+۳+۴ = ۱۰. پیشنهاد حل برای داوری/کلاس: جدول سه‌ستونی «i — s — نتیجهٔ هر دور» روی تخته؛ همین جدول‌کشی روش رسمی حل سوالات مرحلهٔ اول المپیاد است.

### سوال ۴ — حلقهٔ شرطیِ دوگذر ★★★ (چالش این بسته)
```rust
let mut n = 6;
let mut c = 0;
while n > 1 {
    if n % 2 == 0 {
        n = n / 2;
    } else {
        n = n + 1;
    }
    c = c + 1;
}
println!("{} {}", n, c);
```
خروجی چیست؟

**پاسخ: «1 4».** — مسیر n را قدم‌به‌قدم دنبال کنیم: ۶ زوج است → ۳ (دور ۱)؛ ۳ فرد است → ۴ (دور ۲)؛ ۴ زوج است → ۲ (دور ۳)؛ ۲ زوج است → ۱ (دور ۴). حالا ۱ است و شرط `n > 1` برقرار نمی‌شود؛ پس چاپ می‌شود: n=1 و c=4. این سوال همان خانوادهٔ معروف «حدس کولاتز» است که بارها در المپیادهای مختلف آمده — این‌جا با اعداد کوچک و ساده‌شده.

## دستهٔ ب — «چند بار اجرا می‌شود؟» (تحلیل حلقه)

### سوال ۵ — شمارش با شرط ★★
```rust
for i in 1..=10 {
    if i % 3 != 0 {
        println!("سلام");
    }
}
```
کلمهٔ «سلام» چند بار چاپ می‌شود؟

**پاسخ: ۷ بار.** — حلقه روی اعداد ۱ تا ۱۰ می‌چرخد (۱۰ دور)؛ چاپ وقتی انجام می‌شود که i مضربِ ۳ نباشد. مضرب‌های ۳ در این بازه: ۳ و ۶ و ۹ یعنی ۳ عدد؛ پس ۱۰ منهای ۳ می‌شود ۷ بار. نکتهٔ آموزشی: به‌جای شمردنِ تک‌تکِ ۷ عدد، «کل منهای ردشده‌ها» را حساب کنیم — همین میان‌بُر است که در سوال‌های بزرگ‌ترِ المپیاد کار می‌کند.

### سوال ۶ — حلقهٔ تودرتو ★★★
```rust
let mut count = 0;
for i in 1..=3 {
    for j in 1..=i {
        count = count + 1;
    }
}
println!("{}", count);
```
خروجی چیست؟

**پاسخ: ۶.** — دور اول i=1 است و حلقهٔ داخلی ۱ بار می‌چرخد؛ دور دوم i=2 و ۲ بار؛ دور سوم i=3 و ۳ بار. جمع: ۱+۲+۳ = ۶. حلقهٔ تودرتو پایهٔ مفهوم «پیچیدگی» است؛ این نسخهٔ کوچکش برای شروع کافی است.

## دستهٔ ج — «جای خالی را کامل کن» (نوشتن الگوریتم)

### سوال ۷ — بزرگ‌ترینِ سه عدد ★★
```rust
let a = 5;
let b = 9;
let c = 7;
let mut m = a;
if b > m {
    m = b;
}
// این‌جا یک خط بنویس
println!("{}", m);
```
یک خط بنویس تا برنامه بزرگ‌ترینِ a و b و c را چاپ کند. خروجی نهایی باید چه باشد؟

**پاسخ:** خط نوشتنی: `if c > m { m = c; }` — و خروجی نهایی ۹ می‌شود. منطق: m از a=۵ شروع می‌شود؛ با b مقایسه می‌شود و ۹ می‌شود؛ سپس باید با c هم مقایسه شود و چون ۷ کوچک‌تر از ۹ است، m روی ۹ می‌ماند. این «الگوی قهرمان‌گیر» (نگه‌داشتن بزرگ‌ترین تا این لحظه) پایهٔ ده‌ها سوال الگوریتمی است.

### سوال ۸ — منطق جمله‌ای ★
جملهٔ زیر را بخوان و فقط یکی از گزینه‌ها را انتخاب کن:
«اگر باران ببارد، زمین بازی خیس می‌شود. می‌دانیم زمین بازی خیس نیست.»
- گزینهٔ ۱) حتماً باران باریده است.
- گزینهٔ ۲) باران نباریده است.
- گزینهٔ ۳) نمی‌شود دربارهٔ باران نظر داد.

**پاسخ: گزینهٔ ۲.** — اگر باران باریده بود، طبق جمله زمین حتماً خیس می‌شد؛ چون خیس نیست، باران نباریده. این همان استدلال «به دنبالِ نتیجهٔ برعکس» (Modus Tollens) است که در سوال‌های منطقیِ مرحلهٔ اول المپیاد به همین سادگی طرح می‌شود.

## دستهٔ د — پازل الگوریتمی و عددی (بدون کامپیوتر)

### سوال ۹ — ترازو و وزنه‌ها ★★★
سه وزنه داریم: ۱ گرمی، ۳ گرمی و ۹ گرمی؛ و یک ترازوی دوکفه‌ای.
می‌توانی با این‌ها ۷ گرم را وزن کنی؟ چطور؟

**پاسخ: بله.** — چیدمان: **وزنهٔ ۹ و وزنهٔ ۱ را در یک کفه می‌گذاریم (۱۰ گرم) و وزنهٔ ۳ را در کفهٔ دیگر کنار جنس**؛ اختلاف دو کفه می‌شود ۱۰ − ۳ = ۷ گرم. پس جنسِ ۷ گرمی دقیقاً تراز می‌شود. راز ماجرا: وزنه‌های ۱ و ۳ و ۹ (توان‌های عدد ۳) با اجازهٔ گذاشتن وزنه در هر دو کفه، هر وزنی از ۱ تا ۱۳ گرم را می‌توانند وزن کنند — همین الگوی «توان‌های ۳» در سوال‌های وزنه‌کشیِ واقعی المپیاد تکرار می‌شود.

### سوال ۱۰ — شمارش مسیرها ★★★
ربات روی جدول ۳×۳ در خانهٔ پایین-راست ایستاده و می‌خواهد به خانهٔ بالا-چپ برسد.
هر قدم فقط می‌تواند «یک خانه به بالا» یا «یک خانه به چپ» برود.
چند مسیر یکتا دارد؟ (مسیرها را می‌تواند روی کاغذ بکشد)

**پاسخ: ۶ مسیر.** — برای رسیدن باید دقیقاً ۲ بار بالا و ۲ بار چپ برود (مجموع ۴ قدم). هر مسیر یک ترتیب از این چهار قدم است: بالا-بالا-چپ-چپ، بالا-چپ-بالا-چپ، بالا-چپ-چپ-بالا، چپ-بالا-بالا-چپ، چپ-بالا-چپ-بالا، چپ-چپ-بالا-بالا = ۶ مسیر. این نسخهٔ خردِ سوال کلاسیک «شمارش مسیر» المپیاد است؛ در نسخهٔ اصلی جدول بزرگ‌تر و پاسخ با فرمول ترکیب است ولی در این سطح شمردن روی شکل کافی است.

### سوال ۱۱ — معمای عدد ★★
عددی دو رقمی را در نظر بگیر که رقم دهگانش دو برابرِ رقم یکانش است و مجموع دو رقمش ۱۲ می‌شود. آن عدد چیست؟

**پاسخ: ۸۴.** — رقم یکان را u بگیریم؛ دهگان ۲u است. مجموع: ۲u + u = ۳u = ۱۲ → u = ۴. پس یکان ۴ و دهگان ۸؛ عدد برابر ۸۴. بررسی: ۴ + ۸ = ۱۲ ✓ و ۸ = ۲×۴ ✓. این «ترجمهٔ جمله به معادلهٔ ساده» در سوال‌های کتبی المپیاد به وفور دیده می‌شود.

### سوال ۱۲ — الگوی چاپ ★★
```rust
for i in 1..=3 {
    for j in 1..=i {
        print!("*");
    }
    println!("");
}
```
شکل چاپ‌شده چیست و در کل چند ستاره چاپ می‌شود؟

**پاسخ: مثلث راست‌گوشه:**
```
*
**
***
```
— مجموع ستاره‌ها: ۱ + ۲ + ۳ = ۶. تفاوت `print!` و `println!` که در درس ۳ کانال آموزش داده شد این‌جا عملاً دیده می‌شود: ستاره‌ها بدون خط جدید کنار هم می‌روند و پایان هر دورِ بیرونی، خط می‌شکند.

## اگر دانش‌آموزی این بسته را کامل حل کرد، مسیر بعدی چیست؟

1. **نمونه سوال رسمی مرحلهٔ اول المپیاد رایانه‌ای** — آرشیو سال‌های گذشته در سایت‌های
   زیر با پاسخ‌نامه منتشر شده و قانوناً همه‌گان در دسترس است:
   - آرشیو سوالات المپیادهای علمی (amoozz.ir — دانلود مستقیم سوال و پاسخ مرحلهٔ اول و دوم)
   - talayiha.ir — ۱۵ سال سوال با دسته‌بندی گراف/برنامه‌نویسی/الگوریتم
   - بخش «بنیاد ملی نخبگان» و پژوهش‌سراها هم نسخهٔ چاپی دارند.
2. **تمرین آنلاین مرحلهٔ دوم‌گونه**: سایت‌های داوری خودکار مثل Quera (فارسی) —
   مسئله را می‌دهند، کد را می‌فرستی و همان‌جا نمره می‌گیرد؛ پلی بین کوییز کاغذی
   و المپیاد واقعی.
3. **سر مشق هفتگی کانال**: از این بسته می‌شود هر هفته ۱ سوال به‌صورت پست
   «چالش کدنویسی» (هشتگ `#چالش_کدنویسی`) منتشر کرد و پاسخ را هفتهٔ بعد.
