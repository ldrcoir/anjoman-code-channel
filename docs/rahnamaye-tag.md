# راهنمای تگ‌های (#) کانال انجمن کدنویسی — سند رسمی هشتگ‌گذاری

**مبنای الزام در شیوه‌نامه (هشتمین دوره، ۱۴۰۵-۱۴۰۴):**
- «در پیام‌های ارسالی داخل کانال حتماً از تگ # مناسب استفاده شود، راهنمای تگ‌های
  مورد استفاده در مستندات اثر ارسال شود.» (شرایط اختصاصی اثر)
- نمون‌برگ داوری: «نظم و انسجام سامانه — استفاده از تگ # برای دسته‌بندی مطالب» (۵ امتیاز)

این سند همان «راهنمای تگ» است و در بستهٔ مستندات اثر ارائه می‌شود.
**قاعدهٔ دائمی:** هشتگ‌ها همیشه *موضوعی*‌اند؛ نام دسته‌بندی داخلی (ترویجی، آموزشی،
رویداد، اطلاعیه، خلاقانه) هرگز به‌عنوان هشتگ یا متن روی عکس/کپشن نمی‌آید.

## جدول هشتگ هر آیتم

| نوع آیتم (بند شیوه‌نامه) | هشتگ ثابت آیتم | هشتگ‌های موضوعی مکمل |
|---|---|---|
| درس «Rust از صفر» (ترویج/آموزش — بند ۱) | `#آموزش_راست` | `#الگوریتم`، `#برنامه_نویسی` |
| معرفی مشاهیر علم و کامپیوتر (بند ۱ — تولید محتوا) | `#معرفی_مشاهیر` | نام شخص (`#خوارزمی`) + حوزه (`#الگوریتم`) |
| معرفی کتاب/منبع/سایت (بند ۵) | `#معرفی_کتاب` | نام کتاب/منبع |
| خبر علمی/مسابقات (بند ۱) | `#خبر_کدنویسی` | `#مسابقات_کدنویسی` |
| چالش و تمرین هفتگی (رویداد) | `#چالش_کدنویسی` | موضوع چالش (`#متغیرها`) |
| فعالیت خلاقانه (بند ۴ — بازی، عکس‌نوشتهٔ خلاق) | `#فعالیت_خلاقانه` | `#بازی_مرورگری`، `#رفیق_مار` |

| گرایش‌های مسابقات (معرفی) | `#مسابقات_کدنویسی` | `#طراحی_وب`، `#هوش_مصنوعی`، `#بازی_سازی`، `#دستگاه_های_هوشمند` |

## قواعد اجرا

1. **هشتگ پایه:** همهٔ پست‌ها `#انجمن_کدنویسی` را دارند.
2. **هشتگ آیتم:** هر پست دقیقاً «یک» هشتگ ثابت آیتم از جدول بالا دارد — همان
   «هشتگ مناسب آیتم» طبق دستور مالک (۱۴۰۵-۰۸-۰۲).
3. **هشتگ موضوعی:** ۱ تا ۳ هشتگ موضوعی مرتبط با محتوای همان پست.
4. **سقف:** جمع هشتگ‌ها در هر پست ۳ تا ۵ عدد؛ بیشتر نشود (نظم داوری).
5. **سازگاری:** هشتگ‌ها بدون نیم‌فاصله نوشته می‌شوند (`#معرفی_مشاهیر` نه
   «#معرفی‌مشاهیر») و فارسی‌اند مگر نام علمی لاتین باشد.
6. **بازبینی:** پیش از هر انتشار، کپشن با همین سند چک می‌شود؛ تغییر هشتگ آیتم
   فقط با تصمیم مالک و با ویرایش همین سند.

## پیوست — وضعیت اعمال روی پست‌های منتشرشده

- پست ۰۱۳ «خوارزمی؛ پدر الگوریتم» (پیام ۴۹، ۱۴۰۵-۰۸-۰۱): هشتگ آیتم
  `#معرفی_مشاهیر` با editMessageCaption به کپشن زنده اضافه شد (۴۵۹ نویسه ≤۱۰۲۴)
  و کپشن آرشیو همگام شد.
- پست‌های آینده: هشتگ آیتم از صف‌ساز طبق جدول بالا می‌آید.

## پیوست گردش ۲۳ (۱۴۰۵-۰۸-۰۲) — قاب کپشن + اصلاح هشتگ پست‌های زنده

**۱) قاب کپشن (دستور مالک: «برای هشتگ‌ها و آی‌دی کانال یک قاب خوشگل درست کن»):**
از این پس پایان کپشن هر پست هر دو کانال داخل قاب دوخطی بسته می‌شود —
ماژول `scripts/caption_frame.py` این کار را خودکار در لحظهٔ انتشار می‌کند
(`roznegar.py` → `apply_caption_frame`). الگو:

╔══════════════════════════════╗
🔗 ble.ir/anjomanfaghihi
#انجمن_کدنویسی #هشتگ_آیتم …
╚══════════════════════════════╝

- لینک داخل قاب همیشه از نام‌کاربری زندهٔ کانال می‌آید (اگر ادمین‌ها آدرس را
  عوض کنند، قاب هم خودکار اصلاح می‌شود).
- هشتگ‌ها هر خط حداکثر ۴ عدد؛ سقف کل ۳ تا ۵ (قاعدهٔ خودِ این سند).
- پانویسِ عکس هم از قبل قاب قرصی دارد (خط عمودی جداکننده، گردش ۲۱).

**۲) اصلاح زندهٔ ۱۰ پست کانال کدنویسی با editMessageCaption (۱۰/۱۰ موفق):**

| پست | پیام | هشتگ آیتم | عمل |
|---|---|---|---|
| ۰۰۶ درس ۱ Rust | ۱۸ | `#آموزش_راست` | اضافه + قاب |
| ۰۰۷ زندگی، مثل یک کد | ۲۰ | `#فعالیت_خلاقانه` | اضافه + قاب |
| ۰۰۸ مجلهٔ مهر | ۲۲ | `#نشریه_انجمن` | جایگزین «#نشریه_الکترونیکی» + قاب |
| ۰۰۹ بازی رفیق مار | ۴۶ | `#فعالیت_خلاقانه` | اضافه + قاب + کاهش به ۵ هشتگ |
| ۰۱۰ درس ۲ | ۲۷ | `#آموزش_راست` | اضافه + قاب |
| ۰۱۱ معرفی کتاب Rust | ۴۱ | `#معرفی_کتاب` (بود) | قاب + کاهش به ۵ هشتگ |
| ۰۱۲ درس ۳ | ۴۲ | `#آموزش_راست` | اضافه + قاب |
| ۰۱۳ خوارزمی | ۵۳ | `#معرفی_مشاهیر` (بود) | قاب |
| ۰۱۴ درس ۴ | ۵۴ | `#آموزش_راست` | اضافه + قاب |
| ۰۱۵ فاطمیهٔ اول | ۵۷ | `#مناسبت` (بود) | قاب |

- پست‌های پایتونی (پیام ۷ و ۹ — کار عرشیا)، کارگاه عرشیا (پیام ۱۲) و پست
  دستی مالک (پیام ۵۱) عمداً دست نخورده‌اند (تقسیم کار ثابت).
- همین ویرایش اثبات زنده‌بودن پست تسلیت فاطمیه است: ویرایشِ پیامِ حذف‌شده
  ممکن نیست و هر ۱۰ پیام ok=true برگرداندند.

## پیوست گردش ۲۴ (۱۴۰۵-۰۸-۰۳) — ممیزی کامل هشتگ هر دو کانال + اصلاحات زنده

**۱) کانال کدنویسی — کشف و اصلاح:**
- پیام ۵۵ کپیِ تکراریِ «درس ۴» بود (باگ دوبارسردن سمت بله؛ نسخهٔ رسمی قاب‌دار = پیام ۵۴)
  → کپی ۵۵ حذف شد؛ پیام‌های ۵۱/۵۲ پست دستی ادمین‌ها هستند و دست نخوردند.
- عرشیا هنگام ویرایش پیام ۵۷ (اصلاح «دخت»←«دختر») کپشن را بدون قاب ذخیره کرده بود؛
  متنِ ویرایش‌شدهٔ ایشان حفظ و فقط قاب پایانی بازساخته شد (۷۰۲ نویسه). پیام ۵۳ هم قاب
  دوباره بسته شد (۵۰۳ نویسه).
- کپشن‌های زندهٔ قدیمی‌تر (۱۸/۲۰/۲۲/۲۷/۴۱/۴۲/۴۶) از API خوانا نیستند (فید updates محدود است)
  — وضعیت آن‌ها مطابق اصلاحات گردش ۲۳ فرض شده و در اولین ویرایش بعدی بازبینی می‌شود.

**۲) صف کدنویسی — ۸ کپشن اصلاح شد (scripts/fix_tags_g24.py):**
درس ۵ ← #آموزش_راست | مجلهٔ آبان ← #نشریه_انجمن (حذف #نشریه_الکترونیکیِ نادرست) |
منابع رسمی ← #معرفی_کتاب | ۴ مناسبت ← #مناسبت — همه اکنون: هشتگ پایه + هشتگ آیتم +
موضوعی، سقف ۵، لینت سالم.

**۳) کانال انرژی:** پست معرفی (پیام ۳) بازانتشار شد با پوستر موتور جدید؛ کپی تکراری ۵
توسط گارد حذف شد؛ پیام ۴ = پست دستی ادمین (دست نخورده). کپشن صف (فاطمیه + نیروگاه
ساوه) همگی هشتگ آیتم درست دارند.

**۴) گارد دوبارسردن:** تابع dedupe_photo_send در roznegar.py — بعد از هر ارسال، فید
updates چک می‌شود و کپی‌های تکراری خودکار حذف و شناسهٔ واقعی در meta ثبت می‌شود.

## پیوست گردش ۲۵ (۱۴۰۵-۰۸-۰۳) — پوستر GPT و پیام‌های بی‌هشتگ

| پیام | پست | عمل |
|---|---|---|
| ۵۱ | پوستر معرفی ChatGPT (پست دستی ادمین، کپشن قبلی فقط «پروب») | کپشن کامل + هشتگ آیتم `#معرفی_کتاب` (بند ۵: معرفی کتاب/منبع/سایت) + `#هوش مصنوعی` `#ChatGPT` + قاب — editMessageCaption ok=true |

اگر مالک هشتگ مستقل `#معرفی_ابزار` را بخواهد، سطر جدول بالا ویرایش می‌شود.
