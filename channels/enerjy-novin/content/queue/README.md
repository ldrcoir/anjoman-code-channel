# پوشه‌بندی صف کانال «انرژی‌پژوهان» — طبق بندهای الف تا ذ شیوه‌نامهٔ ششمین دوره

> دستور مالک ۱۴۰۵-۰۸-۰۲: «مطالب هر دو انجمن را طبق دسته‌بندی شیوه‌نامه پوشه‌بندی کن».
> هر پوشه = بند شیوه‌نامهٔ ششمین دورهٔ مسابقات انرژی‌های نوین.
> نام پوشه/بند هرگز روی عکس یا متن کانال نمی‌آید (قاعدهٔ دائمی).
