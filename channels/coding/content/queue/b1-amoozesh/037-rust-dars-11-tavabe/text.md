انجمن کدنویسی | مدرسهٔ شهید فقیهی

کدِ یک‌بارنوشته، بارها استفاده‌شده

فایل «src/main.rs»:
```rust
fn moadele(a: i32, b: i32) -> i32 {
    (a + b) / 2        // bazgasht
}
fn main() {
    println!("{}", moadele(18, 20));  // seda 1
    println!("{}", moadele(15, 17));  // seda 2
}
# ──── خروجی ────
19
16
```

- **fn**: کلیدواژهٔ تعریف تابع؛ اسمش را خودت انتخاب می‌کنی
- **-> i32**: نوع مقدارِ برگشتی؛ خطِ آخر بدون سمیکالن برمی‌گردد
- **moadele(18, 20)**: صدا زدن تابع: اسم + ورودی‌ها داخل پرانتز

نکته: تمرین: تابعی بنویس که سه نمره بگیرد و معدلشان را برگرداند؛ بعد در main صدایش کن و چاپ کن
