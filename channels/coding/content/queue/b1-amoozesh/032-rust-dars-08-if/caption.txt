تصمیم‌گیری: شرط if

تا حالا برنامه‌های ما خطی بودند؛ از بالا به پایین اجرا می‌شدند. از این درس برنامهٔ خودت مثل خودت تصمیم می‌گیرد: اگر شرط درست بود یک راه، وگرنه راه دیگر. در Rust شرط پرانتز نمی‌خواهد ولی آکولاد اجباری است؛ زنجیرهٔ if / else if / else هم از بالا به پایین چک می‌شود و اولین شرطِ درست اجرا می‌شود. جالب اینکه if یک عبارت است؛ یعنی می‌شود نتیجه‌اش را در یک متغیر ریخت.

🎯 تمرین این درس: شرطی بنویس که اگر امتیاز بازی از رکورد بیشتر شد پیام Rekord jadid! چاپ کند.
