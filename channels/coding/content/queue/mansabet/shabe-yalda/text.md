# شب یلدا
۳۰ آذر

بلندترین شب سال — گرم با هندوانه، حافظ و یک چالش کد

- **چالش یلدایی**: برنامه‌ای بنویس که طول شب و روز شهرت را حساب کند — خروجی‌ات را در کانال بفرست
- **انار و کد**: کنار هندوانه و آجیل، چند خط کد هم بگذار؛ خنده‌دارتر از فال حافظ می‌شود
- **مرور سال**: آخر سال میلادی نزدیک است؛ ببین از مهر تا حالا چه یاد گرفتی و چه ساختی

فایل «yalda.rs»:
```rust
let shab = "deraz";
let kod = "garm";
// شب بلند است، اما کدنویس از آن نمی‌ترسد
```

نکته: یلدا مبارک — ۳۰ آذر ۱۴۰۵
