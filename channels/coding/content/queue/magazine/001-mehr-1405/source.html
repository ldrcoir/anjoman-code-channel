◈ سرمقاله؛ چرا نشریه؟

انجمن علمی‌پژوهشی کدنویسی امسال با یک هدف روشن شروع شده است: ترویج فرهنگ کدنویسی میان دانش‌آموزان و مستندسازی قدم‌به‌قدم این مسیر در کانال انجمن. هر روز درس، هر هفته پست‌های متنوع و هر ماه یک نشریه؛ این نشریه آینهٔ کاری یک ماهِ انجمن است و در قالب PDF برای مطالعه، دانلود و چاپ آماده می‌شود.

در شمارهٔ نخست به سراغ سه چیز رفتیم: خبرهای خودِ انجمن، معرفی زبان Rust که درس‌های روزانهٔ ما روی آن سوار است، و معرفی نرم‌افزار VS Code که کارگاه کدنویسی هر دانش‌آموز است. در پایان هم ترفندی ساده برای ساخت و اجرای پروژه‌ها آورده‌ایم و تقویم ماه آینده را گفته‌ایم.

◈ خبرهای انجمن

آغاز سری «آموزش Rust از صفر»

سری درس‌های روزانهٔ Rust از این ماه شروع شد. درس اول با عنوان «Rust چیست و چرا؟» منتشر شده و از این به بعد هر روز ساعت ۱۰ صبح یک درس جدید در کانال می‌گذاریم: از نصب و اولین برنامه تا متغیرها و چاپ متن. هدف این است که هرکس از صفر شروع کند، بدون اینکه چیزی از قلم بیفتد.

کارگاه عملی جلسهٔ اول برگزار شد

اولین جلسهٔ کارگاه عملی کدنویسی با استقبال اعضا برگزار شد؛ شرکت‌کننده‌ها اولین برنامهٔ خودشان را نوشتند و اجرا کردند. تمرین‌های جلسه در کانال منتشر شده و جلسهٔ بعدی به‌زودی اعلام می‌شود. اگر جایی از تمرین‌ها گیر کردی، همین حالا در کانال بپرس.

مسیرهای مسابقات کدنویسی جشنواره

مسابقات کدنویسی جشنوارهٔ علمی‌پژوهشی پژوهش‌سراها پنج مسیر دارد: برنامه‌نویسی، طراحی وب، هوش مصنوعی، دستگاه‌های هوشمند و بازی‌سازی. شرکت به‌صورت تیم دو نفره است و شرایط عمومی (منطقه، دوره و جنسیت یکسان اعضای تیم) طبق شیوه‌نامه بررسی می‌شود. جزئیات و زمان ثبت‌نام را به‌محض اعلام رسمی در کانال می‌خوانید.

◈ معرفی زبان؛ Rust

Rust زبانی است که سرعت و امنیت را با هم می‌دهد؛ به همین دلیل سال‌ها محبوب‌ترین زبان در نظرسنجی‌های معتبر توسعه‌دهندگان بوده است. Rust بدون زباله‌روب (GC) کار می‌کند و سرعتی هم‌ردیف C دارد، ولی تفاوت اصلی‌اش این است که خطاهای حافظه — همان مشکلات خطرناک زبان‌های قدیمی — را پیش از اجرا، همان موقعِ کامپایل می‌گیرد.

این زبان امروز در پروژه‌های بزرگراهِ دنیای نرم‌افزار نقش دارد: بخش‌هایی از هستهٔ لینوکس، موتور مرورگر فایرفاکس و اجزایی از ویندوز با Rust نوشته شده‌اند. برای دانش‌آموزی که می‌خواهد مفهومی یاد بگیرد و به سؤال «چرا این کد خراب شد؟» جواب دقیق بگیرد، Rust معلم سخت‌گیر ولی مهربانی است.

درس اول سری ما همین نگاه را داد: یک برنامهٔ Rust فقط تابع main می‌خواهد و یک خط خوش‌آمد. کد زیر را ببینید — همان برنامه‌ای که در درس ۱ اجرا کردیم:

src/main.rs
fn main() {
println!("Salam, donya!");
}

خروجی:Salam, donya!
fnتعریف تابع؛ هر برنامهٔ Rust از main شروع می‌شود
println!ماکروی چاپ متن روی صفحه؛ علامت ! آن را از تابع معمولی جدا می‌کند
cargoابزار رسمی ساخت و اجرای پروژه‌های Rust
🦀 تمرین شمارهٔ ۱: در یک جمله بنویس دوست داری با Rust چه چیزی بسازی و به کانال بفرست؛ پاسخ‌های خوب در شمارهٔ بعدی نشریه می‌آید.

◈ معرفی نرم‌افزار؛ VS Code

Visual Studio Code (VS Code) یک ویرایشگر متن رایگان و سبک است که این روزها به رایج‌ترین محیط کدنویسی دنیا تبدیل شده است. سبکی و سادگی‌اش باعث شده برای شروع عالی باشد و در همان حال با افزونه‌ها به یک محیط کامل توسعه تبدیل می‌شود؛ برای درس‌های Rust ما هم افزونهٔ rust-analyzer کافی است.

چند ویژگی که در کارگاه‌ها بیشتر به کارتان می‌آید: ترمینال داخلی (بدون ترک ویرایشگر دستور اجرا می‌کنید)، پشتیبانی کامل از Git برای ثبت تغییرات پروژه، دیباگر برای پیدا کردن خطاها، و تکمیل خودکار هوشمند کد. فایل پروژه‌ها را هم می‌توانید از هر جا باز کنید و همه‌چیز را یک‌جا داشته باشید.

Ctrl+Sذخیرهٔ فایل — قبل از هر اجرایی ذخیره یادت نرود
Ctrl+`باز و بسته کردن ترمینال داخلی
F5اجرای و دیباگ برنامه

◈ ترفند ماه؛ پروژه‌های Rust با cargo

cargo جعبه‌ابزار رسمی Rust است و عمر پروژهٔ شما را از خط اول ساده می‌کند. چهار دستور زیر را بلد باشی، همهٔ درس‌های ما را می‌توانی خودت خانه اجرا کنی:

cargo new salam

ساخت پروژهٔ تازه با نام salam

cargo build

کامپایل پروژه و ساختن فایل اجرایی

cargo run

کامپایل و اجرا — سریع‌ترین راه برای تمرین

cargo check

بررسی سریع درستی کد بدون ساخت فایل اجرایی

نصب خود Rust هم ساده است؛ درس ۲ سری ما قدم‌به‌قدم rustup.rs و اولین پروژه را آموزش می‌دهد.
