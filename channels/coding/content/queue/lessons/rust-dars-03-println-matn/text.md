# چاپ متن با println!
آموزش Rust از صفر — درس ۳

حرف زدن با صفحه؛ با جای‌خالی‌های {}

فایل «src/main.rs»:
```python
println!("Salam, donya!");
println!("javab: {}", 42);
println!("{} + {} = {}", 2, 3, 5);
# ──── خروجی ────
Salam, donya!
javab: 42
2 + 3 = 5
```

- **{}**: جای‌خالی؛ هر {} یک مقدار می‌خواهد
- **ترتیب مهم است**: مقدارها به‌ترتیب در آکولادها می‌نشینند
- **عدد و متن**: println! هر نوع داده‌ای را چاپ می‌کند

نکته: تمرین: خودت را با دو خط println! معرفی کن
