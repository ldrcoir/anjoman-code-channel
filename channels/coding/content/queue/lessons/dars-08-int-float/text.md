# انواع داده؛ int و float
آموزش پایتون از صفر — درس ۸

هر داده یک نوع دارد؛ با type() ببینش

فایل «main.py»:
```python
age = 15        # int
height = 1.65     # float
print(type(age))   # <class 'int'>
print(age + 10)   # 25
```

- **int**: عدد صحیح؛ مثل 15 و 42-
- **float**: عدد اعشاری؛ مثل 1.65
- **نقطه = اعشار**: 5.0 هم float است، نه int
- **type()**: نوع هر داده را نشان می‌دهد

نکته: در تقسیم، پایتون همیشه float می‌دهد: 10 / 2 می‌شود 5.0
