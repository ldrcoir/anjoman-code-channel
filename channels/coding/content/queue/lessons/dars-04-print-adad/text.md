# print با اعداد
آموزش پایتون از صفر — درس ۴

پایتون ماشین‌حساب هم هست

فایل «main.py»:
```python
print(2 + 3)        # 5
print(7 - 4)        # 3
print(6 * 7)        # 42
print(10 / 2)       # 5.0
# ──── فرق گیومه مهم است ────
print("2 + 3")   # فقط متن است؛ محاسبه نمی‌شود
```

- **بدون گیومه**: پایتون حساب می‌کند؛ مثل ماشین‌حساب
- **با گیومه**: پایتون فقط همان متن را چاپ می‌کند

نکته: نمونه‌های ریاضی کتاب درسی، خوراک این سری هستند
