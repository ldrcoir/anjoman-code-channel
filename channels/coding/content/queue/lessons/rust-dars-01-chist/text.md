# Rust چیست و چرا؟
آموزش Rust از صفر — درس ۱

زبانی که سرعت و امنیت را با هم می‌دهد

فایل «main.rs»:
```python
// اولین نگاه به Rust
fn main() {
    println!("Salam, donya!");
}
```

- **سریع**: بدون زباله‌روب حافظه؛ سرعتی هم‌ردیف C
- **امن**: خطاهای حافظه را همان موقعِ کامپایل می‌گیرد
- **محبوب**: سال‌ها محبوب‌ترین زبانِ نظرسنجی توسعه‌دهندگان
- **کاربردی**: هستهٔ لینوکس، فایرفاکس و بخش‌هایی از ویندوز

نکته: درس بعد: Rust را نصب می‌کنیم و اولین برنامه را اجرا می‌کنیم
