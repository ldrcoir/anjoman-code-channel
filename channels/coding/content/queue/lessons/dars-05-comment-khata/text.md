# کامنت‌ها و خطاها
آموزش پایتون از صفر — درس ۵

دو ابزار نجات‌بخش هر برنامه‌نویس

فایل «main.py»:
```python
# این یک کامنت است؛ پایتون نمی‌خواندش
print("سلام")  # کنار کد هم می‌شود
# print("این خط اجرا نمی‌شود")
# ──── نمونهٔ یک خطا ────
print("سلام
SyntaxError: unexpected EOF
```

- **کامنت با #**: توضیح برای انسان؛ پایتون رد می‌شود
- **خطا = راهنما**: پیام خطا را بخوان؛ خط مشکل را نشان می‌دهد

نکته: معیار داوری مسابقات: کدِ کامنت‌گذاری‌شده امتیاز بیشتری دارد
