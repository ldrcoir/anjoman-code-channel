# کامنت‌ها و پیام‌های کامپایلر
آموزش Rust از صفر — درس ۴
انجمن کدنویسی | مدرسهٔ شهید فقیهی

یادداشت برای آدم‌ها؛ خطاها را برای تو ترجمه می‌کند

فایل «src/main.rs»:
```rust
// in avalin comment-e man ast
let shahr = "Tehran";
println!("{}", shahr);
# ──── اگر اشتباه کنی چه می‌گوید؟ ────
error[E0308]: mismatched types
  --> src/main.rs:4:9
  help: expected `i32`, found `&str`
```

- **// یک خطی**: تا آخر همان خط؛ پرکاربردترین کامنت
- **/* بلاکی */**: چند خطی؛ برای توضیح‌های بلندتر
- **/// مستندسازی**: جلد تابع می‌نشیند؛ سند رسمی کد تو

نکته: تمرین: بالای برنامهٔ درس ۳ یک کامنت /// بنویس
