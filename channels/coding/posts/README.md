# آرشیو پست‌های منتشرشدهٔ کانال کدنویسی — پوشه‌بندی طبق شیوه‌نامه

> دستور مالک (۱۴۰۵-۰۸-۰۴): «صدبار گفتم محتوای کانال‌ها هر کدام طبق شیوه‌نامهٔ خود
> پوشه‌بندی کن، خیلی مرتب بگذار روی گیت» + «هر چی که تو شیوه‌نامه نیست میشه خلاقیت
> یا خودش دسته‌بندی خلاقیت داره».
> از گردش ۲۶ هم **صف** و هم **آرشیوِ پست‌های منتشرشده** یک نقشهٔ واحد دارند:
> پوشهٔ بندِ شیوه‌نامه = پوشهٔ والد آیتم. موتور روزنگار (`roznegar.py`) پست جدید را
> خودکار داخل پوشهٔ بندِ همان آیتم آرشیو می‌کند؛ اگر آیتمی بیرون از پوشه‌های بند
> بود، به‌طور پیش‌فرض در `b4-khollagheh/` (خلاقیت) می‌نشیند.

## نقشهٔ پوشه‌های آرشیو (= بندهای شیوه‌نامهٔ هشتمین دوره)

| پوشه | بند شیوه‌نامه | هشتگ آیتم |
|---|---|---|
| `b1-amoozesh/` | برنامهٔ ۴ — آموزش (درس‌های Rust) | `#آموزش_راست` |
| `b1-moarefi-shakhsiat/` | بند ۱ — ترویج و تولید محتوا (مشاهیر) | `#معرفی_مشاهیر` |
| `b1-khabar/` | بند ۱ — اخبار علمی و مسابقات | `#خبر_کدنویسی` |
| `b2-nashriyeh/` | بند ۲ — نشریهٔ الکترونیکی (PDF + جلد) | `#نشریه_انجمن` |
| `b3-chalesh/` | بند ۳ — رویداد/چالش/کارگاه | `#چالش_کدنویسی` |
| `b4-khollagheh/` | بند ۴ — فعالیت خلاقانه + **هر محتوای بیرون از شیوه‌نامه (خلاقیت)** | `#فعالیت_خلاقانه` |
| `b5-moarefi-manabe/` | بند ۵ — معرفی کتاب/منبع/ابزار | `#معرفی_کتاب` |
| `b6-gerayeshha/` | شرایط عمومی — معرفی گرایش‌ها | `#مسابقات_کدنویسی` |
| `b7-mansabet/` | پیام‌های مناسبتی و انگیزشی | `#مناسبت` |

پوشه‌هایی که هنوز پست ندارند (b1-khabar، b6-gerayeshha) با اولین پستِ همان بند
خودکار ساخته می‌شوند.

## قواعد دائمی

1. **خلاقیت = دستهٔ پیش‌فرض هر چیزی که در بندهای بالا نیست** — هیچ محتوایی
   بی‌خانه نمی‌ماند (دستور مالک ۱۴۰۵-۰۸-۰۴).
2. **فرستندهٔ پست دیگر پیگیری/ثبت نمی‌شود** — دستور مالک (۱۴۰۵-۰۸-۰۴):
   «لازم نیست کسی که پست می‌گذارم بدانیم کیه، اصلاً مهم نیست». جدول‌های
   `INDEX.md` از این پس ستون فرستنده ندارند.
3. شمارهٔ سه‌رقمی هر پست سر جای خودش می‌ماند (۰۰۶…۰۱۹)؛ منتقل‌کردن پوشه‌ها با
   `git mv` انجام شد و تاریخچهٔ گیت محفوظ است.
4. نمایهٔ زمانیِ همهٔ پیام‌های زندهٔ کانال: `INDEX.md` (همین پوشه).
5. آمار خودکار: `content/stats.md` و `content/stats.json` (اسکن بازگشتی).
