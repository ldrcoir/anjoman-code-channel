# زندگی، مثل یک کد
نگاه خلاقانه به کدنویسی

تلاش کن، یاد بگیر، ادامه بده

فایل «life.rs»:
```rust
fn main() {        // زندگی
    match start() {     // تلاش کن
        Ok(_) => continue(),  // ادامه بده
        Err(_) => learn(),     // خطا؟ یاد بگیر
    }
}
```

- **خطا = درس**: هر Err یک فرصت یادگیری است
- **ادامه = کلید**: برنامه‌نویس واقعی از match نمی‌ترسد

نکته: یک زبانِ نمونه؛ مفهومش در هر زبان برنامه‌نویسی یکی است
