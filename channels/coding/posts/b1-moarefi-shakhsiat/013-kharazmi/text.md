# خوارزمی؛ پدر الگوریتم
چهره‌های دنیای کامپیوتر
انجمن کدنویسی | مدرسهٔ شهید فقیهی

از نام یک دانشمند ایرانی تا واژهٔ Algorithm

- **ابوجعفر محمد بن موسی خوارزمی**: ریاضی‌دان ایرانی سدهٔ نهم میلادی
- **Algorithm**: واژهٔ الگوریتم از نام او ساخته شد
- **کتاب الجبر**: منشأ واژهٔ جبر در ریاضیات جهان

فایل «algorithm.rs»:
```rust
let algorithm = "مسیر گام‌به‌گام حل مسئله";
// هر برنامهٔ بزرگ، الگوریتم‌های کوچک دارد
```

نکته: الگوریتم یعنی دستورِ قدم‌به‌قدم؛ پایهٔ هر زبانی که یاد بگیری
