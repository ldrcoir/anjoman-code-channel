# آرایه‌ها و حلقهٔ for
آموزش Rust از صفر — درس ۱۰
انجمن کدنویسی | مدرسهٔ شهید فقیهی

فهرست اعداد، یک‌جا و منظم

فایل «src/main.rs»:
```rust
let nomarat = [20, 18, 19];  // nomre-ha
println!("Aval: {}", nomarat[0]);
println!("Tedad: {}", nomarat.len());
for n in nomarat {            // har nomre
    println!("Nomre: {}", n);
}
# ──── خروجی ────
Aval: 20
Tedad: 3
Nomre: 20
Nomre: 18
Nomre: 19
```

- **آرایه**: فهرست ثابت از چند مقدارِ هم‌نوع داخل [ ] با کاما
- **nomarat[0]**: شمارش از صفر؛ صفرم = اولین عدد؛ len() تعدادشان
- **for**: روی همهٔ عضوها می‌چرخد و هر بار یکی را می‌دهد

نکته: تمرین: آرایه‌ای از معدل‌های ۵ نفر بساز و با for همه را چاپ کن؛ بعد تعدادشان را با len() بنویس
