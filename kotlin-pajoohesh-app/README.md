# اپ «دستاوردهای پژوهشی ۱۴۰۴» 📖

اپ آندروید کتاب رسمی **«معرفی دستاوردهای پژوهشی دانش‌آموزان و هنرجویان پژوهشگر و فناور برگزیده»**
(پژوهشگاه مطالعات آموزش‌وپرورش — هفتهٔ پژوهش ۱۴۰۴) — ۲۱۶ صفحه، کاملاً آفلاین و بدون هیچ مجوزی.

## امکانات
- **خواناک ورق‌خور** — انیمیشن سه‌بعدی پیوسته با کشیدن انگشت (کشیدن به راست = صفحهٔ بعد، به چپ = قبل؛ مثل کتاب راست‌چین واقعی)، لبه‌ها برای ورق‌زدن سریع، نوار پرش سریع
- **فهرست ۱۱ بخش** — از جلد و شناسنامه تا فنی و حرفه‌ای، با پرش مستقیم
- **جست‌وجو در کل متن** — نام دانش‌آموز، استان، مدرسه، مسابقه… با پیش‌نمایش متن و پرش به صفحه
- **۶ تم** — کلاسیک کرم، شب مطالعه، کاغذ گرم، سبز آرام، بنفش شفق، طلایی سلطنتی + شب‌خوانی (فیلتر وارونهٔ ملایم صفحات)
- **ادامهٔ خواندن** — جای دقیق خواندن در حافظهٔ گوشی ذخیره می‌شود
- فونت وزیرمتن، اعداد فارسی، طراحی راست‌چین کامل

## بیلد
ورک‌فلو `build-pajoohesh-apk.yml` صفحات کتاب (عکس دانش‌آموزان) را از ریپوی خصوصی
`ldrcoir/pajoohesh-pages` (فایل `assets.zip`) می‌گیرد، داخل `app/src/main/assets/` باز می‌کند و APK می‌سازد.
**عکس دانش‌آموزان هرگز در این ریپوی عمومی نیست** — نه در گیت، نه در Release؛ خروجی فقط آرتیفکت خصوصی است.

## ساختار
```
app/src/main/java/ir/anjoman/pajoohesh/
  Pust.kt          جعبه‌ابزار + ۶ تم
  FontBox.kt       فونت وزیرمتن
  Ketab.kt         لایهٔ داده: صفحات، فهرست، جست‌وجو، حافظهٔ جای خواندن
  SplashActivity   جلد + منوی اصلی + پس‌زمینهٔ متحرک
  FehrestActivity  فهرست مطالب
  KhavanakActivity خواناک ورق‌خور
  JustoJoActivity  جست‌وجوی کل کتاب
  TemHaActivity    تم‌ها
  DarbareActivity  دربارهٔ کتاب (شناسنامهٔ رسمی)
```
